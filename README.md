## 🚀 Sobre o Projeto
Este projeto é uma API RESTful desenvolvida em **Java** com o framework **Spring Boot** para o gerenciamento de um catálogo de produtos de um mercado (Mercado Express). A aplicação permite realizar as quatro operações básicas de um banco de dados (CRUD: Criar, Ler, Atualizar e Deletar).

A API foi conteinerizada com **Docker** e está hospedada na nuvem utilizando a plataforma **Render**, utilizando o banco de dados em memória **H2** para facilitar a correção e validação do projeto.
